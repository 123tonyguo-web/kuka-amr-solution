# 基于KUKA AMR体系的汽配车间物流自动化改造方案
> 工业工程实践项目 | 求职解决方案工程师（实习）作品集

## 📖 项目简介
模拟面向中小型汽配制造企业，运用工业工程IE方法（VSM价值流图）完成车间物流痛点诊断，基于KUKA AMR移动机器人搭建自动化物流数字化方案；配套Plant Simulation仿真验证，完成BOM编制、成本测算与ROI投资回报分析。
同时开发交互式HTML方案演示页面，支持客户按需选配设备、动态测算成本与投资回收期，用于客户方案汇报演示。

## ✨ 项目核心亮点
1. 痛点诊断：采用VSM价值流分析，识别物料搬运冗余、线边库存过高、上下料节拍失衡三大制造浪费
2. 方案设计：基于KUKA KMP600i AMR + KUKA车队调度平台，设计四层数字化集成架构，完成车间布局与工艺流程设计
3. 经济性评估：完整BOM物料清单，多方案比价，ROI测算，静态回收期2.2年
4. 仿真验证：Plant Simulation物流仿真，优化AMR调度策略；达成搬运效率+40%、线边库存-30%、OEE+15%
5. 交互演示：HTML可视化方案页面，支持客户DIY配置设备，实时计算项目投资收益，用于售前方案沟通

## 🛠️ 工具与技术栈
- IE方法：VSM价值流图、产线节拍平衡、BOM编制、项目成本&ROI分析
- 仿真工具：Tecnomatix Plant Simulation
- 绘图与办公：AutoCAD、PPT、Excel（数据透视、成本测算）
- 前端：HTML、JavaScript（交互式ROI计算器，方案可视化页面）
